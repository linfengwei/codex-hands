How to use codex-hands

Let Claude Code operate Windows apps for you: look at the screen, click and type. On a Claude Code Team plan, Claude Code can't do this on Windows by itself; this plugin adds it. You don't type any commands: just copy the text below and paste it into Claude Code.

①Install

You do this only once. Your computer needs the Codex app first ("Codex" by OpenAI, from the Microsoft Store). If it's missing, Claude will tell you.

  1. Open Claude Code (the Code tab in the Claude desktop app, or claude in a terminal).
  2. Copy this message, paste it into Claude Code and send it:
    Paste into Claude Code
    Please install the codex-hands plugin so you can operate the Windows apps on my computer. The plugin is on GitHub: https://github.com/linfengwei/codex-hands. Do these steps in order and tell me the result of each one. If a step fails, stop and tell me what to do:
1. Check that the Codex app is installed: in PowerShell, run Get-AppxPackage -Name OpenAI.Codex. If it isn't, ask me to install "Codex" (by OpenAI) from the Microsoft Store.
2. Check that Node is installed: run node --version.
3. Install the plugin: run claude plugin marketplace add linfengwei/codex-hands, then run claude plugin install codex-hands@codex-hands.
4. Test that it starts: in the folder Claude Code downloaded it to (%USERPROFILE%\.claude\plugins\marketplaces\codex-hands), run node test/smoke.mjs. The output must have the tools: line.
When you're done, remind me to close Claude Code and open it again.
    Claude Code downloads the plugin from GitHub by itself; you don't need to download anything. You don't need to choose in advance which apps it may operate; Claude Code asks you the first time it needs one.
  3. When Claude Code asks "Can I run this command?", choose Allow.
  4. When it says it's done, close Claude Code and open it again. Then you're ready to use it.

②Use

In Claude Code, type /codex-hands:do and then say in plain words which app and what you want done. Claude first takes a screenshot to see the screen, does one action at a time, and takes a new screenshot after each action to check. You can also just ask without the slash command, but then Claude may not always use this plugin.

Paste into Claude Code: just look
/codex-hands:do Take a screenshot of Video Editor as it is now, show it to me, and tell me which page it's on
Paste into Claude Code: get something done
/codex-hands:do In Video Editor, add the second video under "Recently used" to the timeline, then show me a screenshot
Paste into Claude Code: check something
/codex-hands:do Check whether Video Editor's "Export" button can be clicked right now. Don't click it
The first time it uses an app, you're asked. In claude in a terminal, Claude Code shows its own dialog. It is in English unless Windows is set to Chinese:

Why it's sometimes blocked: two gates

Follow one of Claude's clicks from start to finish. The dashed boxes are gates. The Codex app only supplies the program that does the actions; it doesn't need to be open, and it makes no decisions.

  1. Claudedecides to click.
  2. Gate 1: Claude CodeMay Claude use this tool? The first time, you're asked (the second question in ②).
  3. pluginOnce allowed, the click goes to the plugin, and the plugin tells the helper (a program that comes with the Codex app) to do it.
  4. helper asksThe first time it touches Video Editor, the helper asks the plugin back: is this OK?
  5. Gate 2: you're askedIf you chose "Always allow" before, you aren't asked. If not, a dialog asks you (the first question in ②; in the Claude desktop app it's a small Windows window). Apps such as terminals, Claude and Codex are always denied. Claude can't answer for you.
  6. Video EditorAllowed → the helper really clicks, and sends back a screenshot taken after the click.
  7. EscPress Esc at any time and the helper stops right away.
