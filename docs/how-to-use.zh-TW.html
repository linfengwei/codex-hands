codex-hands 使用說明

讓 Claude Code 幫你操作 Windows 上的 app：看畫面、點擊、打字。不用打指令，把下面的話複製貼給 Claude Code 就好。

①安裝

只做一次。電腦上要先有 Codex app（Microsoft Store 的「Codex」，OpenAI 出的）；沒有的話 Claude 會告訴你。

  1. 打開 Claude Code（桌面 app 的 Code 分頁，或終端機裡的 claude）。
  2. 複製這段，貼給 Claude Code 送出：
    貼給 Claude Code
    請幫我安裝 codex-hands plugin，讓你可以操作我電腦上的 Windows app。plugin 在 GitHub：https://github.com/linfengwei/codex-hands。請依序做，每一步告訴我結果，失敗就停下來告訴我怎麼辦：
1. 確認有安裝 Codex app：在 PowerShell 執行 Get-AppxPackage -Name OpenAI.Codex。沒有的話，請我從 Microsoft Store 安裝「Codex」（OpenAI）。
2. 確認有 Node：執行 node --version。
3. 安裝 plugin：執行 claude plugin marketplace add linfengwei/codex-hands，再執行 claude plugin install codex-hands@codex-hands。
4. 試啟動：在 Claude Code 下載它的資料夾（%USERPROFILE%\.claude\plugins\marketplaces\codex-hands）執行 node test/smoke.mjs，輸出要有 tools: 那一行。
做完後提醒我關掉 Claude Code 再打開。
    Claude Code 會自己從 GitHub 下載 plugin，你不用先下載。要操作哪些 app 不用先設定，第一次用到時 Claude Code 會問你。
  3. Claude Code 問「可以執行這個指令嗎？」時，選允許。
  4. 它說完成後，關掉 Claude Code 再打開，就可以開始用了。

②使用

在 Claude Code 打 /codex-hands:do，後面用一般的話說：哪個 app、要做到什麼。Claude 會先截圖看畫面，一次做一個動作，做完再截圖確認。不打斜線直接說也可以，但 Claude 不一定每次都會用到這個 plugin。

貼給 Claude Code：只看不動
/codex-hands:do 截一張 Video Editor 現在的畫面給我看，告訴我它停在哪一頁
貼給 Claude Code：完成一件事
/codex-hands:do 在 Video Editor，把「最近使用」的第二段影片加到時間軸，完成後截圖給我看
貼給 Claude Code：檢查狀態
/codex-hands:do 看一下 Video Editor 現在的「匯出」按鈕能不能按，不要按下去
第一次碰某個 app 時會問你。在終端機的 claude，是 Claude Code 自己的對話框：
codex-hands 想操作 videoeditor.exe（看畫面、點擊、打字）。要允許嗎？示意

為什麼有時會被擋：兩道關卡

跟著 Claude 的一次點擊走一遍。虛線框是關卡。Codex app 只提供操作的程式，本身不用開著，也不做任何決定。

  1. Claude決定點一下。
  2. 關卡 1：Claude Code能不能用這個工具？第一次會跳出來問你（② 的第二個問題）。
  3. plugin通過後交給 plugin，plugin 再叫 helper（Codex app 附的程式）去做。
  4. helper 問第一次碰 Video Editor，helper 回頭問 plugin：可以嗎？
  5. 關卡 2：問你你選過「一律允許」就不問；沒選過，就跳出對話框問你（② 的第一個問題；在 Claude 桌面 app 是一個 Windows 小視窗）。終端機、Claude、Codex 這類 app 一律拒絕。Claude 不能替你回答。
  6. Video Editor允許 → helper 真的點下去，回傳點擊後的截圖。
  7. Esc任何時候按 Esc，helper 立刻停。
